# Cloud & DevOps Hands-On Labs

## Overview
This repository contains hands-on cloud and DevOps labs completed as part of the KodeKloud Engineer program. The labs simulate real-world infrastructure, automation, and deployment scenarios across AWS, Azure, Linux, Docker, Kubernetes, CI/CD, and Infrastructure as Code.

## What This Demonstrates
- Real-world cloud infrastructure management
- Linux systems administration
- Containerization and orchestration
- CI/CD pipelines and automation
- Infrastructure as Code (Terraform, CloudFormation)
- Production-style troubleshooting

## Lab Categories
- AWS Cloud Infrastructure
- Linux & Networking
- Docker & Kubernetes
- CI/CD with Jenkins
- Configuration Management (Ansible)
- Infrastructure as Code (Terraform)
- Azure Cloud Services

## Why This Matters
Each lab mirrors tasks commonly performed by:
- Cloud Support Engineers
- Systems Administrators
- DevOps Engineers
- Site Reliability Engineers

All labs include documentation, validation steps, and interview talking points.
